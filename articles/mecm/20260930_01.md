皆様、こんにちは。Configuration Manager / WSUS サポート チームです。

Configuration Manager Current Branch バージョン 2609 が、早期更新リング (Early update ring) 向けにリリースされました。  
この記事では、公開情報と現時点の提供状況をご案内します。新機能の詳細や個別の更新手順は、末尾の参考リンクにある公開情報をご確認ください。  

バージョン 2609 は、Configuration Manager Current Branch が年 2 回から年 1 回のリリース サイクルへ移行する最初のバージョンです。  
変更の背景と今後の予定は、[Configuration Manager のリリース サイクルが年 1 回に変わります](https://jpmem.github.io/blog/mecm/20251215_01/)をご覧ください。  

## 早期更新リングでの提供について

2026 年 9 月 30 日時点で、2609 は早期更新リング(Early update ring) で提供されています。  
インストールするには、[チェックリストの「早期更新リング」](https://learn.microsoft.com/ja-jp/intune/configmgr/core/servers/manage/checklist-for-installing-update-2609#early-update-ring)に記載されたオプトイン スクリプトを実行してください。  
オプトイン後、[Configuration Manager コンソール] の [管理] > [更新とサービス] で更新プログラムの表示を確認できます。

2609 の更新プログラムは、バージョン 2503 以降を実行するサイトに適用されます。  
更新前に必ず[チェックリスト](https://learn.microsoft.com/ja-jp/intune/configmgr/core/servers/manage/checklist-for-installing-update-2609)で前提条件をご確認ください。

通常の更新リングでの提供時期は、現時点で確認できる公開情報には記載されていません。  
以前のバージョンのご案内は[Configuration Manager Current Branch 2603 がリリースされました](https://jpmem.github.io/blog/mecm/20260507_01/)をご参照ください。
